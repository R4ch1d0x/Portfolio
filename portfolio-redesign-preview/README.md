# Portfolio color preview

This isolated preview keeps the existing portfolio homepage structure and interactions, with only its color palette adapted to the red/cyan prototype.

- Open `index.html` directly, or serve the repository root with a static HTTP server.
- `index.html` mirrors the main portfolio homepage and links to the existing pages and assets.
- `palette.css` overrides colors from the shared stylesheet; `site.js` is a local copy with paths adjusted for this folder.
- The main portfolio files are unchanged. No dependencies or framework migration are required.
